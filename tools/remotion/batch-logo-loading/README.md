# Batch Logo Loading Animation

Remotion source for the Batch launch/loading mark.

The composition uses `public/logo-loading.svg` as the source mark and renders the app asset to:

`../../../Levain/Assets.xcassets/BatchLogoLoading.dataset/batch-logo-loading.mp4`

Commands:

```bash
npm install
npm run still
npm run render:app
npm run preview
```
